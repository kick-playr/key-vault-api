# Live Swagger documentation

User delegated the choice between generated and live Swagger. Use @nestjs/swagger 12 (compatible with Nest 12 and Node 24) to generate OpenAPI from live controller metadata; serve bundled Swagger UI at /docs and JSON at /docs-json.

- Document the exact supported subset: secret/key CRUD and version metadata, RSA-OAEP-256 operations, reconciliation, snapshots, and namespace path aliases.
- Include explicit request/response schemas, validation limits, errors, bearer auth, required environment/tenant headers, API version query and per-operation permissions. No live credential/config values in schemas or examples.
- Allow GET/HEAD documentation/assets through the existing loopback host check. Maintain API authentication/authorization. Permit same-origin browser requests so Swagger Try it out works; reject other Origins. Disable credential persistence and external schema validation.
- Normalize generated path parameters and unique operation IDs across alias/optional-version paths. Keep request schemas separate from public response schemas so private key fields are never advertised.
- Verify real HTTP UI/assets/JSON, schema coverage/refs/alias parameters, authenticated same-origin requests, continued unauthorized/cross-origin rejection, full tests, build, typecheck and dependency audit.
